# Skærmbilleder

Friske skærmbilleder af den nuværende app (designmanual, officielt logo, onboarding-test, board builder og CMS). Desktop 1440x900, mobil 390 px. Optaget mod en frisk seedet database med mock-leverandører. Ældre materiale ligger i `docs/legacy/`.

## Offentlige sider

- [`offentlig/01-forside.png`](offentlig/01-forside.png) – Forsiden med hero, «sådan virker det» og prisberegner med «fra»-priser.
- [`offentlig/02-priser.png`](offentlig/02-priser.png) – Prissiden med pristabel (fra-priser) og prisberegner.
- [`offentlig/03-login.png`](offentlig/03-login.png) – Log ind med det officielle logo i headeren.
- [`offentlig/04-privatliv.png`](offentlig/04-privatliv.png) – Privatlivspolitik.
- [`offentlig/05-nulstil-adgangskode.png`](offentlig/05-nulstil-adgangskode.png) – Nulstil adgangskode (anmod om link).
